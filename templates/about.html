About Our Technology

AI Technology Overview

Our breast cancer classification system uses a ResNet50-based deep learning model trained on the BreakHis dataset to analyze histological images and classify them as benign or malignant. ResNet50 was selected as the best-performing architecture after comprehensive testing of multiple models.

Key Features:
  • ResNet50-based transfer learning
  • Pre-trained on ImageNet for better feature extraction
  • Real-time image analysis
  • Superior accuracy and confidence scoring
Technical Specifications:
  • Input Size: 128x128 pixels
  • Architecture: ResNet50 + Custom Head
  • Framework: TensorFlow/Keras
  • Training Dataset: BreakHis v1

Model Architecture

Our model is based on ResNet50, a proven deep residual network architecture that excelled in comprehensive testing against other state-of-the-art models including EfficientNetV2B0, InceptionV3, and VGG16.

ResNet50 Base Model:
  • 50-layer deep residual network
  • Pre-trained on ImageNet dataset
  • Residual connections for better gradient flow
  • Global Average Pooling for feature aggregation
Custom Classification Head:
  • Dense layer with 256 neurons and ReLU activation
  • L2 regularization (0.02) to prevent overfitting
  • Dropout layer (60%) for regularization
  • Output layer with 2 neurons (binary classification)
Training Configuration:
  • Optimizer: Adam with learning rate 1e-5
  • Loss function: Categorical crossentropy
  • Metrics: Accuracy, Precision, Recall, AUC
  • Data augmentation: rotation, zoom, flips
Model Selection Process:
  • Tested 4 different architectures
  • ResNet50 showed superior performance
  • Comprehensive evaluation on BreakHis dataset
  • Best accuracy and F1-score results

Dataset Information

The model is trained on the BreakHis dataset, a comprehensive collection of breast histological images.

Dataset Details:
  • Name: BreakHis v1
  • Images: 7,909 microscopic images
  • Classes: Benign and Malignant
  • Magnifications: 40X, 100X, 200X, 400X
Sample Distribution:
  • Benign: 2,480 images
  • Malignant: 5,429 images
  • Format: PNG images
  • Resolution: Various sizes (normalized to 128x128)
